# Convenciones del vault

- Usar enlaces wiki (`[[nota]]`) entre documentos del vault.
- Mantener nombres de carpetas numerados para navegación estable.
- Actualizar la nota de dominio y la de interfaz en el mismo cambio que altere un endpoint o estado.
- Las decisiones permanentes se registran como ADR en `08_DECISIONES`.
- No guardar secretos, datos reales de usuarios ni copias de bases de datos.
